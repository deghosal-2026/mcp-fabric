# Support

## Getting Help

- **Documentation**: See the [docs](docs/) and [README](README.md) for guides, configuration reference, and troubleshooting.
- **Discussions**: Use [GitHub Discussions](https://github.com/deghosal-2026/mcp-fabric/discussions) for questions, ideas, and community support.
- **Issues**: Report bugs and request features via [GitHub Issues](https://github.com/deghosal-2026/mcp-fabric/issues).
- **Security**: Report security vulnerabilities privately to security@ghosal.dev (see [SECURITY](SECURITY.md)).

## Before Opening an Issue

1. Search existing issues and discussions for your question.
2. Check the [troubleshooting guide](docs/guides/troubleshooting.md) for common problems.
3. Provide logs, error output, and steps to reproduce.

## Commercial Support

For enterprise support, SLAs, and consulting, contact the maintainers at conduct@ghosal.dev.
