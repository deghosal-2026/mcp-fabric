# Development Guide

How to set up a local development environment for MCP Fabric.

## Prerequisites

| Tool | Version | Purpose |
|------|---------|---------|
| Python | 3.12+ | API runtime |
| Poetry | 1.8+ | Python dependency management |
| Node.js | 20+ | UI development |
| npm | 10+ | UI dependency management |
| Docker | 24+ | Running PostgreSQL, Redis, and OPA locally |
| Docker Compose | 2.x | Multi-container orchestration |

## Clone and Setup

```bash
git clone https://github.com/deghosal-2026/mcp-fabric.git
cd mcp-fabric

# Install Python dependencies
poetry install

# Install UI dependencies
cd ui && npm install && cd ..
```

## Running the API

### Using Uvicorn (Direct)

```bash
poetry run uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

The API starts at `http://localhost:8000`. OpenAPI docs at `http://localhost:8000/docs`.

### Using Uvicorn with Database Services

Start PostgreSQL and Redis first, then run the API:

```bash
# Start infrastructure
docker compose up -d postgres redis

# Run migrations
poetry run alembic upgrade head

# Start API
poetry run uvicorn api.main:app --reload
```

## Running the UI

```bash
cd ui && npm run dev
```

The UI development server starts at `http://localhost:3000` and proxies API requests to `http://localhost:8000`.

## Running Tests

### Full Test Suite

```bash
make test
```

This runs `poetry run pytest tests/ -v --cov=api --cov-report=term-missing`.

### Test Categories

| Command | Scope | Mark |
|---------|-------|------|
| `make test-unit` | Unit tests (fast, no ext. deps) | `-m "unit"` |
| `make test-integration` | API routes with test DB + mock MCP servers | `-m "integration"` |
| `make test-e2e` | Full stack with real PostgreSQL, Redis, OPA | `-m "e2e"` |
| `npm test` | UI tests (Vitest) | — |

### OPA Policy Tests

```bash
make opa-test
```

Runs `opa test policies/ -v` to validate Rego policies.

## Database Migrations

| Command | Action |
|---------|--------|
| `make db-migrate` | Apply all pending migrations |
| `make db-migrate-new msg="description"` | Create a new migration |
| `make db-downgrade` | Rollback the last migration |
| `poetry run alembic current` | Show current migration version |
| `poetry run alembic history` | Show migration history |

### Manual Migration Commands

```bash
# Create autogenerated migration
poetry run alembic revision --autogenerate -m "add_capability_aliases"

# Upgrade to specific revision
poetry run alembic upgrade abc123

# Downgrade by N steps
poetry run alembic downgrade -3
```

## Docker Compose

Run the full stack with one command:

```bash
docker compose up
```

This starts:

| Service | Port | Purpose |
|---------|------|---------|
| API (`api`) | 8000 | FastAPI application |
| Worker (`worker`) | — | Celery worker (async tasks) |
| Beat (`beat`) | — | Celery beat scheduler |
| UI (`ui`) | 3000 | React admin dashboard |
| PostgreSQL (`postgres`) | 5432 | State storage |
| Redis (`redis`) | 6379 | Cache, broker, sessions |

Build from source:

```bash
docker compose up --build
```

Run specific services:

```bash
docker compose up api postgres redis
```

## Development Workflow

### Code Style

- **Python:** Ruff (line-length 100, select E, F, I, N, W, UP, B, C4, SIM)
- **TypeScript:** ESLint + Prettier (via `eslint-config-prettier`)
- **Type hints:** Required on all public Python functions (mypy strict mode)

```bash
make lint     # ruff check + ESLint
make format   # ruff format + Prettier
make typecheck # mypy strict
```

### Makefile Targets

| Target | Description |
|--------|-------------|
| `make dev` | `docker compose up` |
| `make test` | Full test suite with coverage |
| `make test-unit` | Unit tests only |
| `make test-integration` | Integration tests only |
| `make test-e2e` | E2E tests only |
| `make lint` | Run ruff + ESLint |
| `make format` | Auto-format Python + TypeScript |
| `make typecheck` | Run mypy type checking |
| `make db-up` | Start PostgreSQL + Redis containers |
| `make db-migrate` | Run pending migrations |
| `make db-migrate-new` | Create new migration (`msg=`) |
| `make db-downgrade` | Rollback last migration |
| `make clean` | Remove containers + cache files |
| `make opa-test` | Run OPA policy tests |

## Local Dev with SQLite

By default, the API uses SQLite for zero-dependency development:

```bash
# No Docker required — runs entirely locally
poetry run uvicorn api.main:app --reload
```

The database file is `fabric.db` in the project root. To reset:

```bash
rm fabric.db && make db-migrate
```

## Local Dev with PostgreSQL

```bash
# Start PostgreSQL
docker compose up -d postgres

# Set DATABASE_URL
export DATABASE_URL=postgresql+asyncpg://fabric:fabric@localhost:5432/mcp_fabric

# Run migrations
make db-migrate

# Start API
poetry run uvicorn api.main:app --reload
```

## Environment Variables

See `docs/guides/configuration.md` for the full reference.

Key development defaults:

| Variable | Default | Note |
|----------|---------|------|
| `DATABASE_URL` | `sqlite+aiosqlite:///fabric.db` | Swap to PostgreSQL for prod-like dev |
| `REDIS_URL` | `redis://localhost:6379/0` | Not needed for basic API-only dev |
| `SECRET_KEY` | `dev-secret-change-me` | Change in production |
| `ENVIRONMENT` | `development` | Controls validation and behavior |
