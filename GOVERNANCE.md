# Governance

## Scope

MCP Fabric is a composable tool mesh for MCP ecosystems — a control plane that
sits between MCP servers and AI agents, providing registry, capability normalization,
policy enforcement, approvals, and audit.

## Maintainers

See [MAINTAINERS.md](MAINTAINERS.md) for the current list of maintainers.

## Decision Making

This project uses **lazy consensus** — any maintainer may propose a change.
If no objections are raised within 72 hours, the proposal is accepted.
Significant architectural changes require a minimum of 2 maintainer approvals.

## Release Cadence

- **Patch releases**: As needed for bug fixes and security updates.
- **Minor releases**: Every 4-6 weeks for features and improvements.
- **Major releases**: When breaking API changes are required, with deprecation
  notices in at least one prior minor release.

All releases follow [Semantic Versioning 2.0](https://semver.org/spec/v2.0.0.html).
