# Log in

[Log in with GitHub](https://www.bestpractices.dev/auth/github?locale=en)

Log in with GitHub will automatically perform a sign up if necessary. Sign up will only occur if you authorize the sign up to GitHub; you'll need to re-authorize this if you've only signed in to bestpractices.coreinfastructure.org (our domain name has changed). If you sign up, your name (as provided to GitHub) and GitHub nickname will be shown publicly, and you can change your name at any time. Your email address will be kept private and only used for badging-related interactions; we will not provide it to third parties unless it is legally required.
